find() est une methode qui return le premier element d'un tableau qui correspont a une condition donner (si il n ya aucun element find return undefined)

findIndex() est une methode qui return l'index du premier element qui correspont a une condition (si il n ya aucun element findIndex return -1)

some() est une method qui return true si la condition exist dans au moins un seul element du tableau et false si la condition n'exist pas dans le tableau
